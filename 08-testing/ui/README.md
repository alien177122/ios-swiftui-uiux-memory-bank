# UI тесты (XCUITest)

- Тестируй каждый экран: рендер + ключевые элементы.
- Каждый переход туда и обратно.
- Валидации форм: неверный ввод → те же тексты ошибок.
- Error/empty: mock 500 / пустой ответ.
- Используй accessibilityIdentifier для стабильности.
- Запускай на двух размерах: SE и Pro Max.
