# iOS SwiftUI UI/UX Memory Bank

Структурированная база знаний (дерево папок) по грамотному, лаконичному и эффективному UI/UX на SwiftUI/iOS.
Используется как подсказка при реализации экранов и фич.

## Как пользоваться
1. Найди задачу/экран в дереве папок.
2. Прочитай README.md в нужной папке — принципы, паттерны, примеры.
3. Применяй к коду проекта; при расхождении фиксируй в DECISIONS.md.

## Структура
- 00-overview — общие принципы HIG
- 01-foundation — цвета, типографика, отступы, иконки
- 02-navigation — табы, стек, шторки, deep links
- 03-components — кнопки, поля, карточки, списки, формы
- 04-screens — типовые экраны
- 05-states — загрузка/пусто/ошибка/оффлайн
- 06-accessibility — Dynamic Type, VoiceOver, motion
- 07-animation — переходы, хаптика, жесты
- 08-testing — юнит/UI/скриншоты
- 09-architecture — MVVM, данные, сеть
