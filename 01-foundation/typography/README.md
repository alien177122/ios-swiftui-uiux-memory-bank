# Типографика

- Используй SF Pro через text styles: .largeTitle, .title, .title2, .title3, .headline, .body, .callout, .subheadline, .footnote, .caption.
- Не задавай фиксированные размеры шрифта; уважай Dynamic Type.
- Жирность: .bold/.semibold для заголовков, .regular для текста.
- Моноширинный шрифт (.monospaced) для чисел/кодов.
- Ограничивай длину строк ~60-80 символов.
