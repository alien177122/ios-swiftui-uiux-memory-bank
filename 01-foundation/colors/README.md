# Цвета

- Определяй в Asset Catalog: light + dark для каждого.
- Семантические имена: BackgroundPrimary, TextPrimary, Accent, Error, Success.
- Не хардкодь hex в коде; используй Color("Name").
- Контраст: текст на фоне ≥ 4.5:1 (WCAG AA).
- Бренд-цвет из web → AccentColor.
- Избегай чистого чёрного/белого; используй system backgrounds.
