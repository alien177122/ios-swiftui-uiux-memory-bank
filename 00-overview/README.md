# Общие принципы (Apple HIG)

- Нативный iOS-вид: не калька веба. Используй системные компоненты.
- Ясность > украшательство. Один главный акцент на экран.
- Согласованность: spacing 4/8/12/16/24; radius 8/12/16; единые шрифты.
- Безопасные зоны (safeArea), избегай наложений.
- Dark mode обязателен: семантические цвета из Asset Catalog.
- Dynamic Type: используй text styles (.title, .body, .caption), не фиксированные размеры.
- Haptics на ключевых действиях (успех/ошибка/выбор).
- Pull-to-refresh на списках данных.
- Пустые/ошибочные состояния обязательны.
- Навигация: системный swipe-back, не ломай.
